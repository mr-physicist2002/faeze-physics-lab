# Artwork and audio

- `dist/assets/music.mp3`: the user's original `2. Can You Hear The Music.mp3`, copied unchanged. Playback begins after a user gesture.
- `dist/assets/faeze.png`: the previously generated transparent character, retained only for the home and flower scenes. Its alpha channel is preserved.
- `dist/assets/favicon.svg`: original code-drawn star mark.
- All laboratory apparatus and diagrams are original code-drawn line art. No stock illustration is embedded in a lab.

The user's three reference images guided the paper palette, serif headings, restrained color and simple ink strokes. They were visual references, not copied interface assets. The static lab-teacher asset from version 2 was removed.

The original Faeze character was generated with the built-in image-generation tool using the user's character sheet: one smiling full-body character, preserving the blonde hair, round glasses, white headband and gray outfit, offering a pink flower on a green stem, against a transparent background. No new image generation was used for the scientific diagrams.
